# ORBIT ARCADE 质量分级与下一代 2D / 3D / 4D 路线

**基准日期：2026-11-02。分级是根据实现和设计的编辑评估，不代表已经完成 57 款真人通关或获得玩家评分。**

## 一、先做减法而不是盲目加量

57/57 已接入可运行游戏界面，但“可启动”不等于“好玩”。继续保留所有游戏文件和直达 URL，网站只对主游戏库与公开实验室进行分流。

- **优先体验候选（10）**：tetris、snake、2048、minesweeper、match3、reversi、sokoban、tower-defense、space-shooter、racing。这些值得下一轮集中优化，并非已经达到商业精品标准。
- **基础可玩（30）**：可进入主游戏库，但仍需真实玩法体验验证。
- **公开实验室（17）**：暂不参与随机推荐和精选展示；允许试玩、报告问题和再次晋级。实验不是“代码损坏”的同义词。

## 三、晋级验收标准（不可仅凭自动化全绿）
1. 规则正确：能从开始打到一个明确成功/失败结局，重置、暂停、存档不残留错误状态，并有核心机制自动化测试。
2. 手机可玩：在 390px 手机视口中关键触控区域应尽量达到 44×44 CSS 像素；无点击遮挡，横屏/竖屏适配合理。
3. 目标有意义：玩家必须能做出影响结果的选择，关卡和难度不是固定顺序反复点击。
4. 视觉音效一致：每个作品有独立识别性、恰当操作反馈；音乐类必须有真正同步的音乐，不靠提示音冒充。
5. 真人验证：至少 5 名未参与开发的玩家；目标 4/5 可独立学会第一关、3/5 愿意再开一局。保留失败证据，不虚构反馈。
6. 发布可追溯：记录版本、设备、规则回归和试玩发现；没有真人数据时只能写“编辑候选”。

## 四、新游戏方向：不要为维度而维度

### 2D：先证明精品能力
集中做一款 **星际弹幕射击 / roguelite** 或 **高完成度平台跳跃**，强调关卡、操作、节奏、粒子反馈、音频、难度递进。已有 Canvas 2D 足够做高质量原型，不必为了“技术高级”重写全部代码。

### 3D：先做小而完整的飞行游戏
候选：**低多边形太空穿越 / 飞行竞速**。功能包括可控飞行惯性、镜头、动态障碍、计时、重试、渐进关卡。
引擎研究优先 [Three.js](https://threejs.org/docs/) 或 [Babylon.js](https://doc.babylonjs.com/)；3D 需要独立渲染入口，使用 WebGL 的兼容路径，WebGPU 可作为增强选项。资源应固定版本并自托管，以保留离线/低成本特性。

### 4D：实现真正四维**空间**规则，而不是把“随时间变化”包装成四维
候选：**超立方空间迷宫（Hypercube Shift）**。游戏世界使用 `(x, y, z, w)` 四个空间坐标、4D 旋转和 4D 连通关系；屏幕以 3D 投影或 3D 切片呈现，玩家可操作 `w` 查看截面并寻找原本不相通的道路。
第一版先完成数学内核、操作说明和 5 个能解释“第四空间维”的谜题，再做粒子和高端着色。显示器仍是 2D，不应宣称直接显示了真正四维空间。

## 五、架构约束
`GAMES_DATA.qualityTier` = `candidate | standard | lab`，与技术可运行状态独立。
`GAMES_DATA.dimension` 当前所有作品均为 `2d`。后续加入 3D/4D 时应使用独立的 Renderer/Runner 接口（start / pause / reset / dispose / resize），不要把现有 Canvas 2D 引擎假冒 3D 通用渲染器。

**顺序**：公开实验室分流 → 修复规则/手机触控问题 → 优选 1 款精品 2D → 3D 原型 → 4D 空间玩法验证 → 将表现优良的游戏重新晋级。

## 六、第一款独立玩法内核旗舰：NEBULA STRIKE

- 入口：`space-shooter.html`；核心：`orbit-nebula-core.js`；视听交互：`orbit-nebula-strike.js`。
- 三波递进战斗结束后出现三选一强化；三次选择之后进入最终 Boss 阶段。失败与击败 Boss 均进入明确终态，并回到统一重玩入口。
- 敌人至少三种独立形态和攻击行为，Boss 具有追踪弹幕、红色预警光束与阶段增援；玩家拥有短暂无敌冲刺与升级选择。
- 核心逻辑以固定 60Hz 时间步更新，种子随机数可重放；独立单元测试验证升级、Boss 状态、伤害和冲刺状态；浏览器交互测试验证手机触控与页面控制。
- **注意**：这是可验收的首个更完整 2D 作品，不代表已通过真实玩家 5–10 人的耐玩性调查；美术和音频仍需真实试玩复核，不把编辑候选称为已验证的精品。
