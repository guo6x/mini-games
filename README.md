# ORBIT ARCADE · 浏览器小游戏实验室

包含 **57 个真实 HTML 游戏入口**。目标是离线可用、移动/桌面可玩、无需付费第三方资源。

## 现状（2026-11-02）

- **26 款独立玩法重制**，有明确规则、操作与可重复的计分或通关机制。
- **31 款保留原游戏逻辑的经典作品**，已经进行统一导航、移动端基础检查；仍需实际长时间游玩验证难度曲线和美术细节。
- **0 个旧版计时加分占位页面**：四个原型已替换。原先占位的国际象棋、填字、纸牌接龙、七巧板现在具备实质玩法。
- 所有页面在目录中都有实际文件；没有指向不存在游戏文件的入口。
- **自动测试 ≠ 人工体验质量证明**。最高分保存在本机，非联网排行。

### 主要功能

- 搜索 / 分类 / 收藏 / 最近游玩 / 随机挑战 / 状态明确的游戏大厅
- 跨设备自适应视觉布局与统一返回、帮助、暂停、重开
- 真实实现的赛车、平台跳跃、塔防、三消、迷宫、黑白棋、推箱子、蛇梯棋、数织、心算、泡泡射击、经营、钓鱼、宠物养成、地理问答、字母寻词、拼图、麻将、杀手数独、换装、弹珠台、国际象棋、填字、纸牌接龙和七巧板等 26 款
- 桌面键盘操作和多数游戏的触控操作；浏览器不必联网也可打开（建议通过 HTTP 服务运行）

### 快速运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

### 质量检查

```bash
node --check arcade-home.js
node --check arcade-play.js
node --check arcade-completion.js
node --test tests/arcade-health.test.cjs
# 已安装 Playwright+Chromium 并在 :4173 启动静态服务器后：
node tests/browser-smoke.cjs
node tests/legacy-audit.cjs
```

### 已知限制

- 31 款早期作品沿用各自的游戏引擎，并不与 26 款重制游戏共享所有功能。
- 当前测试覆盖目录一致性、26 款重制的启动/基本交互及早期页面的移动端载入。它不等价于全局高水平玩法、美术或平衡性验收。
- 不提供联网账号、排行榜或云端存档。
- 报告缺陷： https://github.com/guo6x/mini-games/issues
