# ORBIT ARCADE · 经典小游戏实验室

一个纯前端、无需安装的网页游戏实验室。目标不是堆砌游戏数量，而是让每一款游戏真正可玩、有反馈、能重试。

## 状态（2026-11-02 品质重建）

- 仓库中存在 **57 个独立游戏 HTML 页面**。
- 其中 **26 个页面在初步静态审计中包含占位逻辑；此分支已用真实游戏机制替换 **10 个**，剩余 **16 个**为待完善原型。
- 另有 **31 个旧版游戏页面**暂保留原逻辑；它们并不因此自动获得「通过功能测试」的结论。
- 目录现在只登记真实存在的游戏页面，不再有指向不存在 HTML 文件的入口。
- **本轮共 41 个可探索入口 / 16 个待完善原型**；「可探索」不等于全量质量验收通过。

### 本轮重做的 5 个玩法

| 页面 | 机制 |
|---|---|
| racing.html | 四车道闪避、护盾、能量拾取、逐渐提速 |
| platformer.html | 横版移动与跳跃、物理落点、星币、死亡复活 |
| tower-defense.html | 自由布塔、升级、资源收益、无限波次 |
| match3.html | 相邻交换判定、匹配、连锁消除、限时积分 |
| maze-runner.html | 随机迷宫生成、路线探索、三关结算 |

共同能力：暂停/重开、键盘及触控操作、音效开关、浏览器本地最高分。

### 追加的 5 款益智/策略游戏

| 页面 | 机制 |
|---|---|
| reversi.html | 黑白棋翻转、合法落子、简单电脑对手 |
| sokoban.html | 三关推箱子、关卡结算、Z 键撤销 |
| snake-ladder.html | 与电脑轮流掷骰、蛇/梯转移、胜负结算 |
| nonogram.html | 三张 7×7 数织图、行列提示、逐格填色 |
| math-game.html | 四则运算、四选一、限时连击奖励 |

### 结构

- \`index.html\` + \`arcade-home.css/js\`：新游戏大厅、搜索、收藏、筛选、最近游玩。
- \`games-data.js\`：与仓库实际 HTML 页面对应的唯一目录。
- \`arcade-play.js/css\`：五款重新实现的小游戏，不依赖外部库。
- \`arcade-shell.js/css\`：旧游戏的渐进式导航/视觉增强，不替代其游戏规则。
- \`tests/\`：目录一致性和页面基础检查。

## 运行

\`\`\`bash
python3 -m http.server 8000
# 打开 http://localhost:8000
\`\`\`

无需构建，无需数据库；浏览器本地的收藏、最近游玩和最高分不跨设备同步。

## 自动检查

\`\`\`bash
node --check arcade-home.js
node --check arcade-play.js
node --check arcade-shell.js
node --test tests/arcade-health.test.cjs
\`\`\`

如果有 Node + Playwright 和 Chromium，可进一步执行 \`node tests/browser-smoke.cjs\`（需要先在 4173 端口启动 HTTP 服务）。

## 待办与边界

- 16 个旧占位原型还不是真正可玩作品，不应当作已完成游戏传播。
- 其余旧作品仍需逐一做浏览器人工游玩、移动端触控和边界条件测试。
- 高分为本地存储，不提供联网排行；没有承诺其他玩家的成绩可见。
- 不应未经授权复制第三方品牌素材或游戏音效。

欢迎通过 [Issues](https://github.com/guo6x/mini-games/issues) 报告具体卡顿、崩溃、无法操作或玩法反馈。
